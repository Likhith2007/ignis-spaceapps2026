SECTION 16 // RISK REGISTER & PROMPT LIBRARY
Pre-Agreed Answers to the Weekend’s Bad Nights

Every failure mode has a named fallback; every fallback has a prompt already written.

RISK // FIRMS API
Day-range cap or rate limit blocks NRT pulls
Fallback: loop smaller windows per AOI and cache responses in artifacts; if the API degrades fully, the committed archive spine plus last good NRT delta still powers the entire demo — the site never depends on a live call.
RISK // VIIRS RECORD
Sensor outage or gaps distort recent weeks
Fallback: the anomaly engine marks weeks with <80% expected passes as low-confidence in products; UI grays them; the digest skips flagged weeks — honesty rendered as behavior.
RISK // CI
Actions queue delays or 60-day cron disable
Fallback: manual workflow_dispatch does everything cron does (demo the manual path); event weekend is fresh activity so disable rules are moot; queue delay is absorbed by the 6-hour cadence design.
RISK // SCOPE
Feature creep eats the video window
Fallback: the H42 gate fires regardless of feature state — P9 starts on time because a submitted 90% beats an unsubmitted 100%. Parking-lot items are named in the project page as future work (judges read ambition as maturity).
