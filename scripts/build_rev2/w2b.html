SECTION 02 // THE NASA API ARSENAL
Six Families, Exact Endpoints, Zero Guesswork

Every input the app consumes, with its URL pattern, auth, and limits — verified before the event.

The build consumes six NASA data families, and all six are free, documented, and reachable over plain HTTPS. The critical path uses only the first two rows of the table below — FIRMS for the fire record itself, GIBS for map context — and the rest enrich the product: MCD64A1 burned area validates the harmonized calendar against physical truth, POWER supplies fire-weather context for the report panels, and EONET converts big anomaly spikes into named, citable events. Each family’s auth model is deliberately simple: one free MAP_KEY, one free Earthdata login, and nothing else. The Hour 0–2 data check in the war schedule pings every row of this table before the challenge commitment, so no rate limit or schema surprise is discovered mid-build.

SECTION 03 // THE HARMONIZATION ENGINE — FULL SPECIFICATION
Two Sensors, One Calendar, Written as Arithmetic

Deterministic, documented, and implementable by a chat assistant in one focus cycle.

The engine turns two sensor archives into one activity calendar in five steps, each of which is a pure function a judge can audit. Step 1 — unify the schema. Every detection, from either sensor, becomes {date, lat, lon, sensor, satellite, frp_mw, conf_raw, conf_q, daynight}, where confidence is remapped to a shared four-band scale. Step 2 — calibrate the sensors. On the 2012–2025 overlap, VIIRS 375 m reliably out-detects MODIS 1 km (smaller pixels, finer thresholds); the engine measures that gap rather than assuming it: for each cell-month it computes the ratio of high-confidence VIIRS detections to high-confidence MODIS detections, then smooths those ratios into a seasonal transfer function k(month) per region. The pre-2012 MODIS-only era is inflated by k into “VIIRS-equivalent” detections — a conservative, disclosed correction, with k floored at 1.0 so it never deflates a detection.

Step 3 — compute the Fire Activity Index. Per 0.25° cell and day, FAI = α·N_scaled + β·log₁(₁+FRP_sum) with defaults α=1, β=0.5 — a blend of detection count and radiative power that resists both tiny-flare noise and single-megafire domination; defaults are stated and sensitivity-tested in the methodology page. Step 4 — climatology and anomalies. Weekly FAI (ISO weeks) against a 2003–2019 baseline per week-of-year and cell yields mean and standard deviation; the anomaly is a plain z-score, highlighted at |z| ≥ 2. The baseline stops at 2019 so recent extreme years cannot normalize themselves. Step 5 — validate. Monthly FAI totals are correlated with MCD64A1 burned area per AOI (target Pearson r ≥ 0.6); the coefficients land on the methodology page. A calendar that survives that check is not a visualization — it is a measurement.

PSEUDOCODE // HARMONIZE.PY — HAND TO THE DATA SESSION VERBATIM
load detections(aoi, sensor) → unified schema   # FIRMS archive CSVs, then NRT append
remap_conf: MODIS 0-100 → Q1(≥80) Q2(50-79) Q3(30-49) Q4(<30); VIIRS h/n/l → Q1/Q2/Q3
keep conf_q in {Q1,Q2} for FAI   # Q3+ kept for event cards only
k[month] = median over cells of count(VIIRS Q1) / count(MODIS Q1) on 2012–2025 overlap
scale: N_modis_era ×= max(k[month], 1.0)   # pre-2012 → VIIRS-equivalent
fai[cell,day] = 1·N_scaled + 0.5·log1p(sum FRP_mw) on 0.25° grid
weekly[year,week] = sum fai over days → calendar grid
clim[week_of_year] = mean,std of weekly[2003..2019] → z = (x−mean)/std
events = DBSCAN(eps=0.3°, min_samples=5) on weekly detections → top by FAI
validate: pearson(monthly_fai, mcd64a1_burned_area) per AOI → report if r ≥ 0.6
write products: calendar.json, clim.json, events.json, meta.json (k table + lineage)
HONESTY CLAUSE // WHAT WE CLAIM AND WHAT WE DO NOT
We claim a disclosed, reproducible bias correction, not a perfect sensor model. The methodology page states the transfer function’s construction, its seasonal smoothing, the FAI constants, and the validation coefficient — and names the limitations (375 m vs 1 km pixel mixing, nighttime detection asymmetry, small-fire under-detection pre-2012). Judges reward candor calibrated with numbers; the r-value is the proof, the limitations are the credibility.
